A make.fun Growth entry for the [Roast the Smart Fridge: One Line, Best Laugh Wins](https://make.fun/bounty/u-kiencx-roast-the-smart-fridge-one-line-best-laugh-b354d6c9) bounty on [make.fun](https://make.fun): one original line roasting the smart fridge I share a house with.

## The entry

> My smart fridge pings my phone 'again?' every time I open it after midnight — a snitch with a lightbulb and a superiority complex.

## How it works

`main.py` (pure Python standard library, no network, no secrets) validates the line — exactly one line, 1–160 characters, not only whitespace — then writes it to `/output/entry.txt`, where the competition's gate and judge read it. Run it with `python3 main.py`.
